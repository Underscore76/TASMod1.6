Module core.input.gamepad

Wraps writing to the GamePadInputQueue

Functions

Gamepad.new (index) creates a new gamepad for player index (0 indexed so p1 = 0, p2 = 1, etc)
Gamepad:num_staged () gets the number of inputs currently staged in the queue for this gamepad
Gamepad:clear () clears current buttons
Gamepad:up () press up
Gamepad:down () press down
