Module core.utilities.frame_stack

Desc: frame stack utility defines a utility stack class for working with frames allows pushing and popping frames from the stack and fast resetting the game to the frame on top of the stack

Functions

fs.last () get the last frame on the stack
fs.print () print the frame stack
fs.push (f) push a frame to the stack
fs.pop () pop a frame from the stack
fs.clear () clear the frame stack
fs.rw () fast reset the game to the last frame on the stack (NON-BLOCKING)
fs.brw () fast reset the game to the last frame on the stack (BLOCKING)
