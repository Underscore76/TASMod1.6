Module core.fileio

fileio - utility functions for reading/writing files

Functions

exists (name) checks if file exists
read_file (fname) reads lines from a passed file into a table array
write_file (fname, lines) writes lines from a table array to a passed file
read_file_table (fname) reads a file into a table of key-value pairs (simple number/string pairs, not nested) strings that represent numbers will be coerced to number type
write_file_table (fname, tab) writes a table of key-value pairs to a file (simple number/string pairs, not nested)

writes lines from a table array to a passed file

  • fname string the filename to write to

reads a file into a table of key-value pairs (simple number/string pairs, not nested) strings that represent numbers will be coerced to number type

Parameters:

  • fname string the filename to read from

Returns:

    table a table of key-value pairs read from the file
