Module core.utilities.tile_funcs

methods for working with positioning inside of a tile

Functions

tileFuncs.ContainedRect (rect, tile) is the rect fully inside the tile
tileFuncs.ContainedCenter (rect, tile) is the center inside the tile
tileFuncs.ContainedRectCentered (rect, tile) is the rect centered in the tile
tileFuncs.CenteredWithinTileWidth (vec, tile) offset direction to center the player box horizontally in the tile
tileFuncs.CenteredWithinTileHeight (vec, tile) offset direction to center the player box vertically in the tile
tileFuncs.FullyWithinTileWidth (vec, tile) offset direction to have the player box fully inside the tile horizontally
tileFuncs.FullyWithinTileHeight (vec, tile) offset direction to have the player box fully inside the tile vertically
tileFuncs.VecWithinTileWidth (vec, tile) check if the x coordinate of the vector is within the tile bound
tileFuncs.VecWithinTileHeight (vec, tile) check if the y coordinate of the vector within the tile bound
tileFuncs.PlayerBBoxCenter () returns the center of the players bounding box
tileFuncs.PlayerPosition () returns the position of the player
